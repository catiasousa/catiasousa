## Hi there 👋

I have experience in hiring and a strong interest in deep tech, infrastructure, and open source. I've been building AI-assisted workflows for talent sourcing and discovery across GitHub, Hugging Face, and arXiv, with a focus on surfacing high-signal candidates and making the process more useful for technical teams.

- [GitHub Talent Radar Native Claude](https://github.com/catiasousa/GitHub-Talent-Radar-Native-Claude) — Claude-native GitHub talent sourcing workflow to discover, score, and track software/AI engineering candidates by public code activity.
- [HuggingFace Talent Radar Native Claude](https://github.com/catiasousa/HuggingFace-Talent-Radar-Native-Claude) — Claude-native Hugging Face talent sourcing workflow to discover, score, and track ML/AI candidates by published model activity.
- [arXiv Talent Radar Native Claude](https://github.com/catiasousa/arXiv-Talent-Radar-Native-Claude) — Claude-native arXiv talent sourcing workflow to discover, score, and track candidates across AI/ML, systems, security, optics/photonics, math, and more.
- [GitHub Talent Radar with Claude, n8n, Airtable](https://github.com/catiasousa/GitHub-Talent-Radar-with-Claude-n8n-Airtable) — n8n workflow template to source GitHub candidates, score with Claude, and save to Airtable.
- [HuggingFace Talent Radar with Claude, n8n, Airtable](https://github.com/catiasousa/HuggingFace-Talent-Radar-with-Claude-n8n-Airtable) — automated Hugging Face talent sourcing with n8n, Claude, and Airtable.
- [arXiv Talent Radar with Claude, n8n, Airtable](https://github.com/catiasousa/arXiv-Talent-Radar-with-Claude-n8n-Airtable) — n8n + Claude + Airtable workflow to source, score, and track arXiv candidates.
